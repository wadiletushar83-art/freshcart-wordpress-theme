# FreshCart – WordPress Grocery Store Theme

FreshCart is a modern and responsive grocery store WordPress theme built with WordPress and WooCommerce.

The theme is designed for online grocery stores and focuses on a clean user interface, responsive design, product browsing, shopping cart, checkout, customer account management, and WooCommerce integration.

## 🚀 Project Overview

FreshCart is a custom WordPress + WooCommerce e-commerce theme developed from scratch.

The project demonstrates custom WordPress theme development, WooCommerce customization, reusable template parts, custom CSS architecture, responsive layouts, and dynamic product functionality.

## ✨ Features

- Modern grocery store design
- Fully responsive layout
- WordPress custom theme development
- WooCommerce integration
- Product listing and product detail pages
- Product categories
- Shopping cart
- Custom checkout page
- Cash on Delivery support
- Order confirmation / Thank You page
- My Account page
- Billing and shipping address management
- Contact page
- Blog section
- Offers section
- Testimonials section
- Newsletter section
- Responsive mobile navigation
- Scroll-to-top functionality
- Custom WooCommerce templates
- Reusable template components
- Performance optimization setup
- Image optimization using WebP support
